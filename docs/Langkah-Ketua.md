# Langkah yang dilakukan ketua setelah menerima paket

1. Ekstrak ZIP. Buka README dan jalankan npm ci + npm run dev. Coba beranda publik, login demo, modal, dan menu mobile.
2. Isi nama lengkap ketua serta deadline internal di PRD. Nama tiga anggota sudah ditetapkan.
3. Buat repository GitHub publik kosong. Push proyek mengikuti README; masukkan URL nyata ke PRD.
4. Undang Suprihatini, Arif Raharjo, dan Felix Nicholas Juan Lee sebagai collaborator menggunakan username GitHub yang mereka berikan. Jangan menebak akunnya.
5. Kirim link Figma, repo, PRD awal dan Instruksi-Anggota.md ke grup. Pastikan semuanya berhasil menjalankan proyek.
6. Suprihatini mengerjakan branch ui; Arif Raharjo branch interaction; Felix Nicholas Juan Lee branch docs-testing. Setiap orang memakai identitas Git sendiri.
7. Tetapkan checkpoint UI, logika, QA/perbaikan, dan integrasi sebelum tenggat dosen. Minta PR per bagian selesai, bukan menunggu semuanya selesai sekaligus.
8. Tinjau/merge, pastikan minimal 5 commit nyata, lakukan clone bersih + npm ci + build dan tes alur akhir.
9. Periksa README dan PRD PDF final bersama Felix. Kumpulkan repo publik, README dan PRD PDF sesuai rubrik.

Nama ketua, tenggat dan URL GitHub belum diberikan; paket ini tidak mengarangnya. Aplikasi final dikerjakan anggota, bukan dianggap selesai pada tahap fondasi ini.

Suprihatini: tampilan sesuai Figma, aset asli dan responsivitas. Arif Raharjo: logika navigasi, pencarian/filter, postingan, chat, aktivitas, rating dan notifikasi demo. Felix Nicholas Juan Lee: pengujian, laporan bug, README dan PRD PDF final. Aku menyiapkan fondasi, PRD awal, repository dan integrasi.

Baca README dan docs/Instruksi-Anggota.md dahulu. Kerjakan pada branch masing-masing, commit bertahap, dan catat prompt AI/perbaikan manual. Saat menyerahkan, kirim PR, cara mencoba hasil, serta kendala yang tersisa. Tenggat internal akan kita tetapkan sebelum mulai.
